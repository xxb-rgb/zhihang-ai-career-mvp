# 智航AI生涯规划助手

面向高校学生的 AI 职业发展初始导航工具，帮助正在探索实习、就业、升学和职业方向的学生，通过轻量化测评完成基础画像构建，并生成职业导航报告与初始机会推荐。

在线体验：  
https://zhihang-ai-career-mvp.vercel.app/


---

## 一、项目简介

「智航AI生涯规划助手」是一个面向高校学生职业探索场景的 Web/H5 MVP。

它的目标不是替代专业就业指导，也不是做心理测评或招聘平台，而是帮助学生在职业探索初期快速完成自我梳理，获得一份结构化、可阅读、可继续优化的职业导航报告。

当前版本为 **V0.1 Mock 体验版**，已实现从首页、信息填写、兴趣测评、技能评估、职业偏好设置，到报告生成、机会推荐、用户反馈的完整体验闭环。

小程序版本搜索：**Zector智途引航**

---

## 二、目标用户

主要用户为高校学生，尤其是：

- 正在探索实习方向的学生；
- 正在准备就业但方向不清晰的学生；
- 正在考虑升学、科研或就业路径的学生；
- 希望了解自己适合优先探索哪些岗位、项目或训练机会的学生。

---

## 三、核心价值

本项目希望解决学生在职业探索早期常见的几个问题：

1. 不知道如何系统梳理自己的专业、兴趣、技能和经历；
2. 对职业方向缺少初始判断；
3. 不知道下一步可以做什么；
4. 缺少一份可保存、可讨论、可继续优化的职业探索材料。

因此，第一版 MVP 聚焦在：

- 帮助学生快速完成自我梳理；
- 生成一份结构化职业导航报告；
- 推荐 3-5 个适合探索的岗位、项目、训练营或比赛机会；
- 通过反馈机制验证报告和推荐是否有价值。

## 五、项目亮点

### 1. 从 0 到 1 完成 AI 产品 MVP

本项目不是静态展示页，而是一个可完整体验的产品 MVP。

它覆盖了从用户输入、测评、画像生成、报告展示、机会推荐到反馈收集的完整闭环。

---

### 2. 产品边界清晰

项目在设计时明确避免将产品做成复杂招聘平台、心理诊断工具或过度承诺型就业产品。

核心边界包括：

- 不做心理诊断；
- 不承诺就业结果；
- 不虚构用户经历；
- 不做绝对化判断；
- 所有报告内容仅供职业探索参考。

---

### 3. 移动端优先

页面布局以移动端体验为优先，适合学生通过微信扫码、高校活动现场或就业指导场景快速访问。

---

### 4. 支持后续真实 AI 能力接入

当前版本使用 Mock 逻辑跑通流程，后续可以平滑升级为：

- Dify / Coze AI 工作流；
- 大模型 API 报告生成；
- AI 输出质量检查；
- 真实机会池推荐；
- 云端数据库保存；
- 运营后台管理。
